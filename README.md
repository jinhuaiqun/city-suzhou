# 苏州城市研究报告

> 一个大龄北京程序员为搬迁苏州所做的系统性调研。
> 覆盖从经济产业到就业、从住房到医疗、从交通到生活成本的全部维度。

***

## 项目背景

本项目的发起者是北京的一名大龄程序员，正在评估从北京搬迁到苏州的可行性。报告从多个维度收集数据和信息，最终目标是回答一个核心问题：

**"去苏州，我能过得更好吗？"**

短期答案是：**是的。** 长答案请读下面各篇报告。

## 核心结论速览

> 本表只收录作者筛选出"口径可比"的指标，供横向粗览。每行**年份、出处、可信度**见文末 \[1]–\[7]；带 `*` 者仓库内无可追溯出处。**刻意未纳入**对苏州明显不利的维度（高考、顶尖医疗、高端薪资上限、人脉圈，见文末"本表不覆盖"）——请勿仅凭此表下判断。

| 指标                |            苏州           |    北京（参照）    |     杭州（参照）    |
| ----------------- | :---------------------: | :----------: | :-----------: |
| 人均可支配收入（2025）\[1] |         80,796 元        | **89,090 元** |    80,017 元   |
| 人均 GDP（2025）\[2]  |         21.3 万元         |  **23.9 万元** |    18.17 万元   |
| 体制内强度 \[3]        |     **11.9%**（全国最低）     | <30%（未披露精确值） |     14.3%     |
| 房价收入比 \[4]        |         **12.6**        |     26.4     |      17.5     |
| 限牌/限行             |         **无限制**         |    摇号+尾号限行   |   摇号+尾号+外地禁行  |
| 996 普遍度 \[5]      |           🟢 低          |    🟡 中\*    |      🔴 高     |
| 35 岁焦虑 \[6]       | 🟢 技术/管理岗；产线普工 35 岁仍被排斥 |   🔴 互联网驱动   | 🔴（正文另一处标 🟡） |
| 公积金非公占比 \[7]      |        **88.1%**        |     >70%     |     85.7%     |

**表注**

- **\[1]** 人均可支配收入，三城均为 **2025 年**各市统计局《国民经济和社会发展统计公报》口径、可直接比：苏州 80,796 元（+4.2%）、北京 89,090 元（+4.3%）、杭州 80,017 元。参考：[苏州市统计局公报](https://www.suzhou.gov.cn/szsrmzf/ndgmjjhshfztjsjfb/202605/0543af82405748cd9ffa4cfc81aecccd.shtml)、[北京市统计局公报](https://www.beijing.gov.cn/renwen/bjgk/rmsh/202603/t20260327_4567665.html)、[杭州市统计局公报](https://www.hangzhou.gov.cn/col/col1229063404/art/2026/art_678cb9baf0c649dd8ac2c58f124c4df3.html)。
- **\[2]** 人均地区生产总值，三城均为 **2025 年**公报口径（按常住人口计算）：苏州 21.3 万元、北京 23.9 万元（全国省级最优）、杭州 18.17 万元（181,732 元）。人均 GDP 越高越好，此列北京领先。参考：北京市统计局《2025 年国民经济和社会发展统计公报》（2026-03 发布）、杭州市统计局《2025 年国民经济和社会发展统计公报》（2026-04 发布）。
- **\[3]** 来源为搜狐城市/澎湃新闻对《各地住房公积金 2023 年报》的**二次分析**，非一手年报，年份 2023，与本表其他行年份不一致。北京源头仅披露区间"<30%"，未给精确值。
- **\[4]** 麟评居住《2024 年全国百城房价收入比》**统一公式**，三城可直接比较，越低越易负担。苏州并非绝对最低——高于二线城市均值（10.8）与万亿城市最低的长沙（约 5.4）。原"房价（中档区）1.5-2.5 万"是苏州相城/吴中非核心区挂牌价、且北京取的是五环外，口径不对等，故以本行替代；苏州园区核心约 3.8-4.2 万/㎡。
- **\[5]** **作者定性评级**，无调研/抽样/官方口径支撑；北京"🟡 中"为编者推测，正文无出处。
- **\[6]** **作者定性评级**。苏州的"容忍度高"仅限技术/管理岗——[就业市场与职场生态 §5.2](就业与生活/苏州就业市场与职场生态.md) 明示产线普工（约占制造业劳动力 60%）"35 岁即被排斥"；杭州评级在该文件内部自相矛盾（§1.3 标 🟡、§4.2 标 🔴）。
- **\[7]** 来源同 \[3]，**含外资企业缴存**（外资产值占比约四成），非纯民企口径。北京非公占比正文原为 ">70%"（与体制内"<30%"互补），此前表中漏填为"—"，已补回。

**本表不覆盖**（这几项苏州明确处于劣势，需另读正文再权衡）：江苏 vs 北京**高考难度**、**顶尖医疗**（三甲数量/全国前十医院）、**高端岗位薪资上限**、离开北京的人脉与社交资本损失。相关讨论见 [宜居性深度分析 §九](宜居/苏州宜居性深度分析.md)、[就业市场 §五](就业与生活/苏州就业市场与职场生态.md) 等。
