# 苏州城市研究报告（精简版）

> 一个大龄北京程序员为"搬不搬苏州"做的调研。核心问题只有一个：**去苏州，我能过得更好吗？**
> 答案一句话：**能——前提是你想要的是"职业寿命长一点、日子稳一点、钱存得下来"，而不是"薪资上限更高"。**

---

## 结论先看

| 维度 | 苏州 vs 北京 |
|---|---|
| 工作机会 | 薪资 25-60 万（低于北京），但**职业寿命更长、35 岁焦虑更低** |
| 能存的钱 | 年薪 40 万：年储蓄 18-24 万（北京 7-16 万），**翻倍级差距** |
| 生活底线 | 看病 / 上学 / 出行 / 空气，**没有一项拖后腿** |
| 硬短板 | 薪资天花板、江苏高考、顶尖医疗、无机场 |

> 一句话：苏州给不了北京的薪资上限，但大概率能给你"不用 40 岁重新找工作"的确定性。
